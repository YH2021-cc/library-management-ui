# 图书管理系统登录界面设计

这是一个为图书管理系统设计的登录界面UI设计项目。

## 项目内容

- `library-login-ui.fig` - Figma源文件（需要在Figma中打开）
- `登录界面设计说明.md` - 详细的设计说明文档
- `设计预览` - 界面设计预览图

## 如何使用

### 在Figma中查看和编辑

1. 访问 [Figma官网](https://www.figma.com)
2. 注册/登录您的Figma账户
3. 从以下方式之一打开设计文件：
   - 通过共享链接直接打开（如有）
   - 上传`library-login-ui.fig`文件到您的Figma账户中

### 获取Figma文件

由于GitHub不支持直接存储和预览Figma文件，您可以：

1. 访问 [这个Figma社区链接](https://www.figma.com/community/file/XXXXX)（请使用实际链接）
2. 将设计文件复制到您的Figma账户中进行编辑

## 设计概览

本登录界面遵循现代UI设计原则，具有以下特点：

- 分割式布局（左侧图像，右侧表单）
- 现代、简洁的色彩方案
- 用户友好的表单设计
- 响应式设计适配不同设备
